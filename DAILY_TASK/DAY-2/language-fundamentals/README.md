# Day 2 — Language Fundamentals + Git Fundamentals

## Project: Monthly Usage Analyser

This project demonstrates Java language fundamentals and Git fundamentals.

---

## 1. Java Language Fundamentals

The project covers the following Java concepts:

- Primitive data types
- Variables
- Constants using `final`
- Arrays
- One-dimensional arrays
- Two-dimensional arrays
- Operators
- Operator precedence
- Ternary operator
- Widening type casting
- Narrowing type casting
- Integer overflow
- Preventing overflow using `long`
- Floating-point precision

---
