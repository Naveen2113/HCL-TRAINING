# Learning Management System (LMS)

## User Stories

### US01 — Create and Publish Courses

**Functional Requirement:** FR1

**User Story:**

> As an Instructor, I want to create and publish courses so that learners can access and learn from my courses.

**Story Points:** 5

**Acceptance Criteria:**
- Instructor can create a course.
- Instructor can add modules and lessons to the course.
- Instructor can provide the required course information.
- Instructor can publish the course.
- Published courses are available to learners.

---

### US02 — Enrol in a Course

**Functional Requirement:** FR2

**User Story:**

> As a Learner, I want to enrol in a course so that I can access its learning content.

**Story Points:** 3

**Acceptance Criteria:**
- Learner can view available courses.
- Learner can select a course to enrol in.
- Learner can enrol in an eligible course.
- The enrolment is stored successfully.
- Learner receives confirmation after enrolment.

---

### US03 — Track Lesson Progress

**Functional Requirement:** FR3

**User Story:**

> As a Learner, I want to mark lessons as complete and have my progress percentage updated so that I can track my course completion.

**Story Points:** 3

**Acceptance Criteria:**
- Learner can access enrolled course lessons.
- Learner can mark a lesson as complete.
- Completed lesson status is stored successfully.
- Course progress percentage is updated.
- Learner can view their current progress.

---

### US04 — Create Assignments with Deadlines

**Functional Requirement:** FR4

**User Story:**

> As an Instructor, I want to create assignments with deadlines so that learners can complete required coursework within a specified time.

**Story Points:** 5

**Acceptance Criteria:**
- Instructor can create an assignment.
- Instructor can provide assignment details.
- Instructor can set a submission deadline.
- Assignment is associated with the appropriate course or module.
- Learners can view the assignment and deadline.

---

### US05 — Submit Assignment

**Functional Requirement:** FR5

**User Story:**

> As a Learner, I want to submit an assignment before its deadline so that my work can be evaluated.

**Story Points:** 3

**Acceptance Criteria:**
- Learner can access assigned assignments.
- Learner can upload an assignment submission.
- System validates the submission deadline using server time.
- Submission is stored successfully.
- Late submissions are rejected.

---

### US06 — Grade Assignment and Provide Feedback

**Functional Requirement:** FR6

**User Story:**

> As an Instructor, I want to grade learner submissions and provide feedback so that learners know how well they performed and how they can improve.

**Story Points:** 5

**Acceptance Criteria:**
- Instructor can view learner submissions.
- Instructor can assign a grade.
- Instructor can provide feedback.
- Grade and feedback are stored successfully.
- Learner can view the grade and feedback.

---

### US07 — Issue Completion Certificate

**Functional Requirement:** FR7

**User Story:**

> As a Learner, I want the system to issue a certificate when I achieve 100% completion and pass so that I have proof of course completion.

**Story Points:** 8

**Acceptance Criteria:**
- System tracks the learner's course completion percentage.
- System verifies that the learner has achieved 100% completion.
- System verifies that the learner has passed the required assessment.
- System generates a completion certificate.
- Certificate has a publicly verifiable ID.
- Learner can access the issued certificate.

---

### US08 — View Learner Progress

**Functional Requirement:** FR8

**User Story:**

> As an Instructor, I want to view learner progress so that I can monitor learner completion and performance.

**Story Points:** 5

**Acceptance Criteria:**
- Instructor can view enrolled learners.
- Instructor can view each learner's course progress.
- Progress percentage is displayed.
- Instructor can identify completed and incomplete learners.
- Only authorized instructors can access learner progress.
